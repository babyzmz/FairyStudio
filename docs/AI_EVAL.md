## 任务 1：改按钮文字

- 起始模板：Counter（`Templates/counter`）。
- 指令原文：「把计数按钮上的文字改成中文"点我计数"，其他不变。」
- 期望检查点：
  1. 只改一处 `Text`（或 Button label），且只动 `Sources/Views/ContentView.swift`；
  2. 变更卡片显示 1 个文件、+/−行各 1；
  3. autoRun 下一次应用并运行成功，无 error 诊断，预览显示中文按钮；
  4. 修复轮数 0。

- 起始模板：待办清单（W1 模板）。
- 指令原文：「给每条待办加一个截止日期字段，默认值为 7 天后，列表里显示出来。」
- 期望检查点：
  1. 模型补丁涉及模型 struct + 列表行视图（且只用 supported / partial 能力，

  2. 校验通过；运行后列表正常渲染；
  3. 记录是否触发修复轮（期望 ≤1）与原因（诊断原文）。
