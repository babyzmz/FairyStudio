## 4. 关键实现决策

- `@Generable` 双路径：SPM（macOS 15 部署目标，宏要求 26+）编译不过，
  故 `#if canImport(FoundationModels) && !SWIFT_PACKAGE` 才加宏；Xcode iOS
  构建走宏路径（Verify 构建已验证展开通过），SPM 走 JSON 代码块解析。
- FoundationAI 不依赖 SwiftRuntime：能力目录由 App 层经
  `SwiftRuntimeEngine.catalog`（public）取条目注入 `ReadCapabilityTool`；
  校验经 `AssistantValidating` 协议，生产实现 `RunCoordinatorValidator`
  快照 `coordinator.engine`（运行时即 SwiftRuntimeEngine）。
- 修复计数跨"校验修"与"运行修"：`PendingChange.repairRoundsUsed` /
  `lastErrorSignature` 透传，`RepairTracker` 统一执行"最多 2 轮，同签名即停"。
- Rx 式取消：`CurrentGeneration`（引用盒，Sendable）同时服务
  @Sendable perform/onPartial 闭包与 MainActor 会话；`Mutex` 不可复制，
  故盒内包 Mutex 而非直接用 Mutex 作属性跨闭包复制（Xcode 下实测的坑）。
