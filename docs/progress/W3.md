## 1. 交付状态（逐项）

### UI 组件
| 能力 | 状态 | 说明 |
|---|---|---|
| Image(systemName:) | supported | 名称透传；`Image("resource")` 显示占位+警告（M1 接入资源） |
| Slider | supported | `value: Binding<Double>` + Int 闭区间 + 可选 step，VM 双向绑定；标签暂不显示（警告） |
| Picker | supported | `selection Binding` + ForEach/静态 Text 行（每行需 `.tag`）；`.pickerStyle(.segmented/.menu/.automatic)` 透传 |
| Stepper | supported（原先没有，实现） | `value: Binding<Int>` + 可选标题/标签/Int 闭区间；step:/onIncrement: 形式不支持 |
| ScrollView | supported | 容器，轴向透传；showsIndicators: 形式不支持 |
| Form / Section | supported | 容器；Section header/footer 只支持字符串 |
| NavigationStack + NavigationLink + navigationDestination | supported | B-2：目标类型只支持 String/Int；path 绑定支持 `[String]` 子集（Int 记为 `i:<数字>`）；修饰符须写在栈内容内部 |
| sheet / alert | supported | B-3/B-4：isPresented Binding<Bool> + 内容闭包；alert 含 title/message/一到两个 Button |
| Spacer / Divider | 已有（无改动） | — |

### 修饰器/生命周期
- `.task` 同步子集完善：与 onAppear 同机制（宿主触发，不自动执行）；体内 `await` 按同步执行（声明侧无 async，故 sound）；不支持取消。
- `.onAppear` 保持；sheet/alert 内容闭包每轮渲染重新求值，捕获的 state 读写直达存储（有单测）。

### 语言
| 能力 | 状态 | 说明 |
|---|---|---|
| enum 关联值 + switch 模式匹配 | supported | 构造（显式/隐式）+ 存储；`.case(let x)` 绑定、字面量混合、`case let` 前缀、where；穷尽性计入 |
| tuple | partial | 构造 + `let (a,b)` 解构（扁平一层，`_` 跳过）+ `.0`/标签访问；解构赋值仍不支持 |
| 带 setter 的计算属性 | supported | get/set（newValue，可自定义参数名）；静态 setter / 计算属性上 mutating 方法调用不支持 |
| inout | supported | 具名函数/方法/init 调用，copy-in/copy-out（装箱+写回）；函数值与动态分派不支持；同变量多传不做独占检查 |
| 单侧范围 | supported（`syntax.range` 备注更新） | `a...`/`..<a`/`...a`：构造、数组下标切片、打印、比较；for-in 单侧报错；Double 不支持 |
| didSet | partial | 存储属性/全局/static，赋值后触发一次（init 内不触发，自体钳制不递归）；mutating 方法整体写回与 `$` 写入不触发；willSet 忽略并警告 |
| String | supported（2 项升级） | replacingOccurrences/trimmingCharacters（去空白）升级；`String(format:)` 子集（仅 `%.Nf` 与 `%%`，Int 按 Double 格式化）新增 `stdlib.String.format` |
| Array | 已有（补覆盖） | sort(by:)/firstIndex(where:)/removeAll(where:)/contains(where:)/allSatisfy/sorted()/reversed()/enumerated() 本就 supported；夹具补 `sort(by:)`、`removeAll(where:)`、`Array(reversed())` 物化行 |
| Dictionary | 已有（无改动） | 遍历/for-(k,v)、default 下标、keys/values/count 本就 supported |
| Double 格式化 | 见 String(format:) | `%.Nf` 与宿主 `String(format:)` 逐字节一致（含 nan/inf/舍入） |
| Date 只读 | supported（新增 `stdlib.Date`） | `Date()`/`Date.now`、description/打印/`==`/`<`；无运算与格式化器 |

### 不做（v1 之外，报 unsupported 诊断）
class / 协议 / 泛型 / actor / async / throws / 宏保持原样；`syntax.ifExpression`、`as/is`、`typealias` 等未动。
VM 确定性：随机 API（`*.random`）仍诊断拒绝；`Date()` 时钟读取是任务书允许的只读基础。

## 6. 环境备注

- `Packages/FairyCore/Package.swift` 在 HEAD 即破损（W1/W2 WIP：缺 `Tests/ProjectCoreTests` 目录、
  `ProjectCore` 编译不过、`FoundationAI` 编译不过），`swift test` 全量构建失败。

- 仓库为多 agent 共享工作树：验证期间观察到兄弟并发改动（Templates、App、ProjectCore、FoundationAI、Package.swift）。
  提交时只 `git add` 本所有权文件；`Tests/FairyStudioTests/SwiftRuntimeIntegrationTests.swift` 的改动非本人所为，未碰。
- 实践经验（给后来者）：`...`/`..<` 前后缀、`case .ok(let x)` 的 `PatternExpr`、`_` 解析为 `DiscardAssignmentExpr`、
  真机 `String(format:)`/`Date` 需 `import Foundation`、`[T].reversed()` 打印的是 `ReversedCollection`（本实现取"返回数组"子集）、
  `%f` 配 Int 实参真机为 UB（本实现按 Double 格式化）、`emit(.callBuiltin)` 的 labels 数量必须与压栈参数数一致（否则宿主级崩溃）。
